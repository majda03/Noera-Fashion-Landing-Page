# Noéra — Fashion Editorial Web Experience

Noéra is a fashion campaign concept built as an editorial web experience rather than a conventional landing page. The project explores large-scale typography, asymmetrical composition, image-led storytelling, motion, and responsive visual hierarchy.

**Live project:** https://majda03.github.io/Noera-Fashion-Landing-Page/  
**Portfolio case study:** https://majdakapetanovic.com/#work

## Creative direction

The visual system combines a warm paper palette, high-contrast editorial typography, a deep red accent, oversized type, magazine-inspired image composition, and intentionally unconventional spacing.

The goal was to make the website feel closer to a fashion campaign or art-direction piece than a reusable business template.

## Interface details

- Full-screen split hero composition
- Editorial display typography with Bodoni Moda
- Fixed navigation treatment
- Loading progress animation
- Large image-led sections
- Marquee-style moving editorial strip
- Asymmetrical grid layouts
- Layered campaign typography
- Responsive layout behavior
- Smooth in-page navigation

## Stack

- HTML5
- CSS3
- Inline animation and responsive styling
- Google Fonts

## Why this project is in the portfolio

Noéra demonstrates visual direction, composition, typography, responsive layout thinking, and the ability to translate an editorial concept into a functioning browser experience.
